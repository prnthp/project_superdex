# OpenArm V2.0 with Wuji Hand 2 (Beta 1)

This directory contains a SuperDex assembly that references:

- OpenArm V2.0 torso: [`../../torsos/openarm_v20`](../../torsos/openarm_v20) - see its README, LICENSE, and NOTICE.
- OpenArm V2.0 arms: [`../../arms/openarm_v20`](../../arms/openarm_v20) - see its README, LICENSE, and NOTICE.
- Wuji Hand 2 (Beta 1): [`../../hands/wuji_hand2_beta1`](../../hands/wuji_hand2_beta1) - see its README, LICENSE, and NOTICE.

The mount assets in this directory (`cad/`, `collision/`, `render/`, `intermediates/`) adapt the Wuji hand to the OpenArm V2.0 end effector. They are Meta proprietary and are distributed under CC BY 4.0; see [`LICENSE`](LICENSE).

For the OpenArm V2.0 assembly with its stock grippers instead, see [`../openarm_v20`](../openarm_v20).
